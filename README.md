# 📊 Sales Performance Dashboard Using Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance using Microsoft Power BI. The dashboard provides interactive visualizations to monitor sales revenue, profitability, customer purchasing patterns, and overall business performance.

The project helps identify sales trends, evaluate product performance, and support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales revenue and profitability.
- Track monthly and yearly sales performance.
- Identify top-performing products and categories.
- Analyze region-wise sales distribution.
- Understand customer purchasing behavior.
- Monitor key business performance indicators.
- Provide actionable business insights.

## 🛠️ Tools and Technologies Used

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated columns and measures
- **CSV/Excel** – Data source
- **GitHub** – Project documentation and portfolio

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

1. **Total Sales Revenue** – ₹25.01M
2. **Total Profit** – Measures overall business profitability.
3. **Total Orders** – Tracks the total number of orders.
4. **Average Order Value** – Measures average revenue generated per order.
5. **Profit Margin** – Evaluates profitability as a percentage of sales.
6. **Total Quantity Sold** – Tracks the total number of products sold.

*Note: The revenue figure assumes the dataset uses Indian Rupees.*
